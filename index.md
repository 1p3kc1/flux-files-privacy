# Flux Files — Privacy Policy / Gizlilik Politikası

**Last updated / Son güncelleme:** 9 October 2026

## English

### Overview
Flux Files is an Android file manager designed to help users browse, organize, search, preview, and manage files stored locally on their devices.

### File access
Flux Files requests storage access to provide file management functionality, including browsing folders, copying, moving, renaming, deleting, restoring, and organizing files.

On supported Android versions, the app may request All Files Access (`MANAGE_EXTERNAL_STORAGE`) to perform its core file management functions.

### APK installation
When a user explicitly chooses to open an APK file for installation, Flux Files may request permission to install apps from this source. This permission is not requested during ordinary app startup.

The installation is handled through Android's system installation process.

### Data processing
Files and their metadata are processed locally on the user's device to support browsing, previews, search, thumbnails, storage analysis, archives, and file operations.

Flux Files does not intentionally upload personal files to developer-operated servers.

### Data collection and sharing
The current intended release does not include advertising, analytics, cloud synchronization, or developer-operated data collection services.

Flux Files does not collect or share user data with the developer or third parties through its own services.

When a user explicitly chooses an Android sharing or external-opening action, the selected external application handles the content according to its own privacy practices.

### Local storage
The app may retain local preferences, cached thumbnails, search information, file-operation history, and Trash records as needed for its functionality.

### Data control
Users can manage their files and local app data using the app's available features and Android system settings. Clearing application data may remove app-managed settings and records.

### Security
Flux Files uses Android's supported storage and permission mechanisms. It does not claim access to protected locations that Android restricts.

### Children's privacy
Flux Files is a general-purpose utility and is not specifically designed for children.

### Changes
This policy may be updated when the application's features or data practices change.

## Türkçe

### Genel bakış
Flux Files, kullanıcıların Android cihazlarında yerel olarak saklanan dosyaları görüntülemesine, düzenlemesine, aramasına, önizlemesine ve yönetmesine yardımcı olan bir dosya yöneticisidir.

### Dosya erişimi
Flux Files; klasörleri görüntülemek, dosyaları kopyalamak, taşımak, yeniden adlandırmak, silmek, geri yüklemek ve düzenlemek için depolama erişimi ister.

Desteklenen Android sürümlerinde temel dosya yönetimi işlevleri için Tüm Dosyalara Erişim (`MANAGE_EXTERNAL_STORAGE`) iznini isteyebilir.

### APK yükleme
Kullanıcı bir APK dosyasını yüklemek üzere açıkça seçtiğinde Flux Files, bu kaynaktan uygulama yükleme izni isteyebilir. Bu izin normal uygulama açılışında istenmez.

Yükleme işlemi Android'in sistem yükleyicisi üzerinden gerçekleştirilir.

Flux Files kişisel dosyaları geliştiricinin sunucularına bilerek yüklemez.

Yayımlanması planlanan mevcut sürümde reklam, analiz, bulut senkronizasyonu veya geliştirici tarafından işletilen veri toplama hizmetleri bulunmamaktadır.

Flux Files kendi hizmetleri aracılığıyla kullanıcı verilerini geliştiriciye veya üçüncü taraflara toplamaz ya da paylaşmaz.

Kullanıcı Android'in paylaşma veya başka uygulamada açma özelliğini açıkça seçerse ilgili içerik, seçilen uygulamanın gizlilik uygulamalarına tabi olur.
